SOBRE // GAME ARENA 2026

SOBRE O PROJETO.

Muito mais do que uma experiência gamer. O Game Arena 2026 é um projeto educativo desenvolvido por estudantes do curso Técnico em Informática do IFRO Campus Ariquemes, na disciplina de Segurança da Informação.

01 // OBJETIVO

VOCÊ SABERIA IDENTIFICAR UM GOLPE?

Nosso objetivo é conscientizar as pessoas sobre os riscos presentes na internet, especialmente os golpes de phishing.

Queremos mostrar como páginas aparentemente confiáveis podem despertar curiosidade e incentivar o fornecimento de dados pessoais.

02 // A EXPERIÊNCIA

COMO FUNCIONA O GAME ARENA?

Criamos uma página fictícia de torneios de jogos eletrônicos, com diferentes modalidades e um formulário de inscrição.

Depois da inscrição, o participante descobre que estava em uma simulação e recebe orientações sobre segurança digital.

03 // PHISHING

O QUE É PHISHING?

Phishing é um golpe que utiliza mensagens, e-mails ou sites falsos para enganar usuários e obter informações.

Os criminosos podem se passar por empresas, instituições ou serviços conhecidos para conquistar a confiança das vítimas.

04 // PREVENÇÃO

COMO SE PROTEGER?

Confira o endereço dos sites, desconfie de mensagens inesperadas e nunca compartilhe senhas ou códigos de segurança.

Antes de fornecer informações pessoais, verifique se a página realmente pertence à instituição que afirma representar.
